# afo-mcp

A Model Context Protocol (MCP) server for SAP Analysis for Office workbooks.

Planned scope:

- **Read** existing workbooks without Excel: data sources, SAP formulas, planning objects and VBA macros, across a whole folder.
- **Operate** workbooks through Excel and the Analysis for Office API on Windows: variables, filters, refresh, planning functions and sequences, saving plan data.
- **Build** workbooks: data sources, layout, planning objects and macros.

Status: early exploration.
